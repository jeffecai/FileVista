# FileVista — 设计系统 v0.1

> 一个现代化的 Windows 双栏文件管理器。视觉母题：**对开账簿（open folio）**——左右两栏是一本书摊开的两页，中间是一道书脊，而不是两块并排的卡片。

## 0. 反套路约束（来自 frontend-design skill）

AI 生成设计的头号特征，本项目**明确禁止**：

- 暖奶油底（≈#F4F1EA）+ 高对比衬线大标题 + 陶土色强调（≈#D97757）
- 近黑底 + 荧光绿/朱红单点强调
- 报纸式通栏 + 零圆角 + 密集分栏的"假编辑风"
- 所有内容切成同一种圆角卡片 + 同一种柔和阴影 + 渐变装饰
- 标题里只给一个词加粗/斜体/变色
- 全大写小标签、内容上方多余的"eyebrow"小字
- 每个区块淡入上浮、每张卡片 hover 过渡

本项目的"纸感"来自**排版、栏线、留白和装订结构**，不来自米黄色。

## 1. 色彩（Light，默认）

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F8F8F5` | 应用底（冷调纸白，非奶油） |
| `--page` | `#FDFDFB` | 文件列表页心 |
| `--ink` | `#17181A` | 主文字 |
| `--ink-2` | `#4B5055` | 次级文字 |
| `--ink-3` | `#7C8288` | 元数据、占位 |
| `--rule` | `#E1E1DA` | 发丝线（1px） |
| `--rule-strong` | `#C9C9C0` | 书脊、分栏线 |
| `--accent` | `#1D3B63` | 墨蓝：焦点、选中标识、链接 |
| `--accent-soft` | `#E8EDF4` | 选中行底色 |
| `--danger` | `#9C3B2E` | 仅用于删除/覆盖，不做装饰 |
| `--warn` | `#8A6A1F` | 冲突、只读 |
| `--shadow-palette` | `0 12px 32px rgba(23,24,26,.14)` | 仅命令面板一层 |

规则：界面里**只有一个强调色**（墨蓝）。砖红只在破坏性操作出现时出现。

## 2. 字体

三件套，两个家族 + 一个等宽：

- **Newsreader**（serif，400/500，光学尺寸 6–72）：品牌字、栏标题、预览标题、空状态。用于"编辑感"，不用于正文列表。
- **IBM Plex Sans**（400/500/600）：界面文字、文件名、按钮。文件名是数据，必须可快速扫读。
- **IBM Plex Mono**（400/500，tabular-nums）：大小、日期、条目计数、路径片段。

字号阶：`11 / 12.5 / 14 / 17 / 22 / 34`（px）。正文行高 1.5，列表行高 1.15。

禁止：全大写标签；标题内单词变色；无意义 eyebrow。

## 3. 栅格与密度

- 4px 基准网格。
- 行高：舒适 30px / 紧凑 26px，可在设置里切换。
- 左内边距 16px，右内边距 12px；列之间 20px。
- **书脊**：两栏之间是 1px `--rule-strong` 线 + 两侧各 12px 留白，中缝正中有一个 3×28px 的浅色握把（可拖动调整栏宽）。
- 无卡片、无圆角容器。唯一圆角：按钮 3px、命令面板 4px、滚动条 6px。

## 4. 结构

```
┌────────────────────────────────────────────────────────────┐
│ 38px 标题栏：FileVista（Newsreader）  ·  当前路径（Plex Mono）  │
│                                        ─  □  ✕（自绘）      │
├──────────────────────────┬─────────────────────────────────┤
│ 标签带（索引标签，非圆角）│ 标签带                           │
│ 运行头：Left · 3 items   │ 运行头：Right · 12 items         │
│ 面包屑 / 路径输入         │ 面包屑 / 路径输入                │
│ ┌ 列头 Name Size Modified┐│ ┌ 列头 ...                      │
│ │ 文件行（虚拟滚动）      ││ │                                │
│ └────────────────────────┘│ └────────────────────────────────┘
│ 状态栏：选中 2 项 · 1.4 MB │ 状态栏                           │
└──────────────────────────┴─────────────────────────────────┘
```

- **标签带**做成书页索引签：文字 + 底部 2px 墨蓝短线表示激活，不画胶囊。
- **运行头**：`Left` / `Right` 用 Newsreader italic 13px，右侧条目数用 Plex Mono 11px。这是唯一的"栏身份"标识。
- **列头**：Plex Mono 11px，句首大写（`Name` / `Size` / `Modified`），无底色，只有下方 1px 发丝线。
- **选中行**：`--accent-soft` 底 + 左侧 2px 墨蓝竖条；不改变文字色。
- **焦点**：1px 墨蓝内描边 + 1px 外偏移，不用发光。
- **预览抽屉**：从右滑入 360px，顶部是 Newsreader 22px 的文件名，正文用 Plex Sans 13px/1.65，代码/文本用 Mono 12px。抽屉左缘 1px 线，不加阴影。

## 5. 动效

- 只有一个时长：`120ms cubic-bezier(.2,.7,.2,1)`。
- 只做**回应动作**的动效：抽屉开合、命令面板出现、行选中条移动。
- 禁止页面加载编排、禁止列表逐项淡入、禁止卡片 hover 抬升。

## 6. 交互模型（"使用方法"重设计）

键盘优先，鼠标不惩罚：

| 键 | 行为 |
|---|---|
| `↑ ↓` | 移动光标（不改变选中） |
| `Shift + ↑↓` | 扩展选择 |
| `Enter` | 进入目录 / 打开文件 |
| `Backspace` | 上一级 |
| `Tab` | 切换左右栏 |
| `Ctrl+L` | 路径输入（当前栏） |
| `Ctrl+T` / `Ctrl+W` | 新建 / 关闭标签 |
| `Ctrl+Tab` | 下一个标签 |
| `F2` | 重命名 |
| `Delete` | 移到回收站（可撤销提示） |
| `Ctrl+Shift+N` | 新建文件夹 |
| `F5` / `F6` | 复制到对栏 / 移动到对栏 |
| `Space` | 预览抽屉 |
| `Ctrl+K` | 命令面板（动作 + 跳转路径 + 最近目录） |
| `Ctrl+1..4` | 聚焦第 N 个标签 |

命令面板是本产品的"使用方法"核心：所有功能可搜索、可键盘执行，按钮只是入口之一。

## 7. 文案语气

- 简短、名词化、不用感叹号。
- 空状态用陈述句，例如：`这个文件夹是空的。` / `没有匹配 "report" 的条目。`
- 错误说明**发生了什么 + 能做什么**，不写"出错了"。
- 状态栏用 `·` 分隔，数字用等宽。

## 8. 不做的事（MVP）

- 不做毛玻璃、不做渐变、不做插画、不做吉祥物。
- 列表、小图标、超大图标三种视图共用一套选择/拖放/排序逻辑；超大图标才请求系统缩略图，避免列表模式产生额外 IO。
- 四宫格是双栏的延伸：2×2 分区、共享中缝比例，标签用罗马数字 I–IV 作为运行头。
- 不做云盘集成、不做标签系统、不做搜索索引（先用当前目录过滤）。
